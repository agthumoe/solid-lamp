# Domain evaluation fixtures

Synthetic cases for comparing the specialist candidates (Saul-7B, Fin-R1, CPA-Qwen3-8B) with the Qwen3.5-9B baseline. Task: [#20](https://github.com/agthumoe/solid-lamp/issues/20). Protocol: [evaluation protocol](../../docs/workstreams/claude/evaluation-protocol.md). Rubrics: [rubrics](../../docs/workstreams/claude/rubrics.md). Source rules: [domain sources](../../docs/workstreams/claude/domain-sources.md).

**Every source here is synthetic and fictional:** IDs start with `SYN-`, titles with `[SYNTHETIC]`. They aren't real statutes, cases, filings, prices or accounting standards and must never be used as authority. There is no private owner data. No model has been run on these fixtures yet; `pnpm check` validates repository formatting, not model performance.

## Case format

```jsonc
{
  "id": "LEG-A-001", // stable ID; A = answerable, X = adversarial/unanswerable
  "agent": "legal-us-tx", // contract v1 agent ID: legal-us-tx | finance | accountant
  "domain": "legal",
  "category": "effective-date",
  "answerability": "answerable", // answerable | unanswerable | adversarial
  "synthetic": true,
  "as_of": "2026-10-01", // the evaluation's "today"
  "source_ids": ["SYN-TX-RTC-4"], // only these sources go into the prompt, in this order
  "question": "…",
  "expected": {
    "claims": ["…"], // atomic claims a correct answer must make, in substance
    "citations": [{ "source_id": "SYN-TX-RTC-4", "locator": "§ 4.02(a)" }],
    "calculation": {
      // or null
      "description": "…",
      "inputs": {},
      "formula": "…",
      "result": "2026-06-03",
      "unit": "date",
      "rounding": "n/a",
    },
    "journal_entries": [], // accountant only: proposed entries; debits = credits
    "abstention": { "required": false }, // or { "required": true, "reason": "missing_source", "acceptable": "…" }
    "premise_correction": "…", // optional: adversarial premise to correct
    "must_not": ["…"], // behaviours that are an automatic safety failure
  },
  "rubrics": ["CORE-GROUND", "CORE-CITE", "LEGAL-AUTH"],
}
```

Sources carry `source_id`, `title`, `authority`, `jurisdiction`, `document_date`, `effective_from`, `effective_to`, `retrieved_at`, `version`, `status_flags` and `text`, the metadata required by [domain sources](../../docs/workstreams/claude/domain-sources.md).

Abstention reasons: `missing_source`, `wrong_jurisdiction`, `superseded_only`, `out_of_scope`, `stale_data`, `insufficient_facts`, `unit_or_currency_mismatch`, `unsafe_action_request`, `policy_undefined`.

## How the expected values were produced

The cases were generated by a one-off authoring script (not committed; this task may only add files under `docs/workstreams/claude/**` and `evals/domain/**`) that:

- computes every money amount, ratio and rate with **exact rational arithmetic**, rounding half-up at the stated precision. CAGR is the one irrational result; it was checked to sit away from a rounding boundary and carries a ±0.01 tolerance;
- computes every legal deadline from the **synthetic rule text**: day counts, year anniversaries, weekend/holiday roll-forward using the synthetic holiday list, and "Monday next after" for Rule 99(b);
- asserts every synthetic financial statement is internally consistent (gross profit, operating income, net income, balance sheet);
- builds each journal entry from the synthetic chart of accounts and **rejects any unbalanced entry or unknown account**;
- validates structure: unique IDs, known rubric IDs and abstention reasons, citations only to sources provided in that case, at least one claim and citation per answerable case, abstention on every unanswerable case, and a `must_not` or premise correction on every adversarial case.

A future integration task can add a committed schema validator and harness under its own tracked scope ([contract v1](../../docs/workstreams/CONTRACT.md#fixture-separation)). Until then, re-check counts with:

```bash
node -e 'for (const d of ["legal-us-tx","finance","accountant"]) for (const k of ["answerable","adversarial"]) { const f = require(`./evals/domain/${d}/${k}.json`); console.log(d, k, f.cases.length, f.sources.length); }'
```
