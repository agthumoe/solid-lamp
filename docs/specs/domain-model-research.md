## Local deployment inference

7–8B Q4 GGUF models are plausible candidates for the RTX 3060 12 GB, based on parameter/weight size and existing host benchmarks. This is an estimate, not a measured residency result. GGUF options exist for [Saul](https://huggingface.co/mradermacher/Saul-7B-Instruct-v1-GGUF), [Fin-R1](https://huggingface.co/Mungert/Fin-R1-GGUF) and [CPA-Qwen](https://huggingface.co/mradermacher/cpa-qwen3-8b-v0-GGUF). Quantizations are third-party artifacts: verify upstream identity, immutable revision, hash, template and license chain. Start with Q4_K_M and a 4K context, then measure quality/memory versus Q5 if feasible. Context, KV cache, desktop VRAM and embedding residency all count.

Use one generation model at a time plus embed, through LlmGate. Keep a tested general model for orchestration/tool safety; call a specialist as a bounded analysis role. Do not give an untested specialist autonomous tool selection/write permissions or keep all specialists resident. Ollama/GGUF import support must be verified, not assumed from a model card's Transformers/vLLM example.

## Domain-agent proposal

Separate `finance`, `accountant`, `tax-us-tx` and `legal-us-tx` agents, each spec-first with independent tools, source scope and evals. Reuse models where testing supports it; an agent need not have its own model. Exact arithmetic, reconciliations and double-entry invariants belong in deterministic code. Model output explains/proposes; writes, filings and other side effects remain approval-gated.

Tax sources: [IRS forms/instructions](https://www.irs.gov/forms-instructions) by tax year and [Texas Comptroller](https://comptroller.texas.gov/taxes/) for applicable Texas taxes. Legal sources: [Texas statutes](https://statutes.capitol.texas.gov/), relevant court rules/opinions and [State Law Library](https://guides.sll.texas.gov/). Index jurisdiction/effective dates and preserve versioned citations; model pretraining cannot establish current law.

[OpenTaxSolver](https://opentaxsolver.sourceforge.net/) is an open-source calculation candidate for supported US personal-return forms; verify the exact year/form scope and rounding, not universal business-tax coverage. [TaxCalcBench](https://github.com/column-tax/tax-calc-bench) supplies tax-calculation test cases, not a tax specialist model; adapt local fixtures rather than running its default cloud provider harness. PSL Tax-Calculator is a policy microsimulation project, not a drop-in filing product.

## Acceptance before adoption

Confirm licenses and provenance; freeze versions; benchmark GPU/context/Ollama compatibility; compare against the existing general baseline on owner-relevant synthetic cases. Test citations, jurisdiction/year correctness, abstention, arithmetic reconciliation, ledger invariants, malformed data and safe tool behavior. Have qualified reviewers check consequential tax/legal/accounting examples. Keep filings and final advice reviewable; no model was installed or approved in this research session.
