# Development governance

Tracking: [GitHub #1](https://github.com/agthumoe/solid-lamp/issues/1).

Goal: establish enforceable standards for AI, API, data, frontend and operations without starting Phase 1 implementation or closing the model-selection gate.

Deliverables: linked handbook, architecture decision, small-component/state examples, reviewed pinned project skills, GitHub templates and phase milestones/issues, CI for currently available checks, refreshed status/plan, committed and pushed baseline.

Acceptance: every requested topic has a decision, an example or checklist, and an implementation phase; canonical AGENTS routes all agents to the handbook and requires a GitHub task before edits; skills preserve provenance and licensing; future checks are explicitly distinguished from checks available now. Tests and documentation integrity checks pass; remote commit is verified.

Non-goals: install application dependencies, execute migrations, publish a dashboard, change model roles, or advance the phase gate. Third-party skills cannot authorize network exposure, cloud inference, destructive SQL, credential access or deployment.
