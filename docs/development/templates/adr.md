# Template: architecture decision record

Copy to `docs/adr/NNNN-<kebab-title>.md` (next free number) for any non-trivial choice. Example: [ADR 0005](../../adr/0005-phase1-stack-and-topology.md).

```markdown
# ADR NNNN: <Decision in a few words>

Date: YYYY-MM-DD. Status: proposed | accepted | superseded by NNNN. Tracking: #NN.

## Context

The forces: requirements, constraints (AGENTS hard constraints, hardware), evidence.

## Decision

What we do, stated so it can be checked in code review.

## Alternatives considered

Each option with the reason it lost.

## Consequences

Good, bad, and "revisit if" triggers.
```
