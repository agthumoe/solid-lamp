## What the existing evidence says

The host audit in [HARDWARE.md](../../../HARDWARE.md) reports an RTX 3060 with 12 GB VRAM. The Windows desktop used 0.8–1.6 GB during observations. WSL exposes 15 GiB RAM; the proposed 24 GB `.wslconfig` change was not applied. Docker Desktop was installed but its daemon was not running at audit; Tailscale was not found. These are dated host observations, not a current host check.

The latest recorded live tuned run is `2026-10-13`, label `tuned-v4`, with flash attention, q8_0 KV cache, at most two loaded models, and one parallel request ([validation notes](../../../VALIDATION.md), [result artifact](../../../bench/results-tuned-v4.json)). It reports 50.7 tok/s for Qwen3.5-9B chat, 77.8 for Qwen3.5-4B router, and 33.1 for Qwen2.5-Coder-14B; its generic tool and residency results match v2 within noise. The v4 RAG exact-format check scored the live answer `I don't know` as a refusal failure because it omitted the final period; harness v5 separates semantic abstention from exact-format scoring. No live v5 benchmark is recorded. The current `pnpm check` exercises synthetic fixtures and stubs; it does not call Ollama or prove domain competence.
